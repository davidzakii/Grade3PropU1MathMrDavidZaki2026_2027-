# تطبيق الرياضيات التفاعلي – الوحدة الأولى

تطبيق تعليمي تفاعلي مصمم لطلاب **الصف الثالث الإعدادي**، يهدف إلى تقديم محتوى الرياضيات بطريقة مبسطة وتفاعلية، من خلال الدروس التعليمية والأمثلة المحلولة والأنشطة والاختبارات، مع متابعة مستوى تقدم الطالب وتحفيزه على التعلم.

## 📚 محتوى التطبيق

**الوحدة الأولى: الأعداد النسبية والقوى والمعادلات الأسية**

تتضمن الوحدة درسين رئيسيين:

### الدرس الأول: القوى

- مفهوم القوة والأساس والأس.
- ضرب القوى ذات الأساس الواحد.
- قسمة القوى ذات الأساس الواحد.
- القوى ذات الأس الصفري.
- القوى ذات الأس السالب.
- قوة القوة.
- أمثلة محلولة وتدريبات تطبيقية.

### الدرس الثاني: المعادلات الأسية

- مفهوم المعادلة الأسية.
- حل المعادلات الأسية بتوحيد الأساسات.
- المعادلات الأسية المتجانسة.
- تطبيقات حياتية على المعادلات الأسية.

## ✨ مميزات التطبيق

- تقسيم المحتوى إلى دروس وأقسام تعليمية منظمة.
- عرض الأهداف التعليمية لكل درس.
- شرح القوانين والنظريات الرياضية.
- تقديم أمثلة محلولة خطوة بخطوة.
- أنشطة تعليمية تفاعلية.
- تدريبات متنوعة لقياس الفهم.
- اختبارات قصيرة (Quizzes).
- مراجعة شاملة للمهارات المكتسبة.
- متابعة تقدم الطالب في الدروس والأقسام.
- تسجيل نتائج الاختبارات والامتحانات.
- تتبع الأخطاء لمساعدة الطالب على تحسين مستواه.
- نظام تحفيزي يعتمد على النجوم والشارات والإنجازات.
- متابعة إتقان المهارات الرياضية.
- إمكانية التبديل بين الوضع الفاتح والداكن.
- إعدادات للتحكم في الأصوات ومستوى صعوبة التدريبات.
- حفظ تقدم الطالب تلقائيًا باستخدام التخزين المحلي للمتصفح.

## 🚀 طريقة التشغيل

لا يحتاج التطبيق إلى تثبيت أي برامج أو إعداد بيئة تشغيل خاصة.

1. تحميل المشروع أو استنساخ المستودع:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. فتح مجلد المشروع.
3. تشغيل ملف `index.html` باستخدام متصفح الإنترنت.

## 💾 حفظ البيانات

يستخدم التطبيق تقنية `Local Storage` لحفظ بيانات الطالب وتقدمه، بما يشمل:

- الدروس والأقسام المكتملة.
- نتائج الاختبارات والامتحانات.
- النجوم والشارات المكتسبة.
- المهارات التي أتقنها الطالب.
- الأخطاء والتحديات.
- تفضيلات العرض والصوت.

**ملحوظة:** تُحفظ البيانات محليًا على المتصفح والجهاز المستخدم، ولا تتم مزامنتها تلقائيًا بين الأجهزة المختلفة.

## 🎯 الهدف من المشروع

تقديم تجربة تعليمية تفاعلية تساعد الطلاب على فهم الرياضيات وإتقان مهاراتها من خلال التعلم المنظم والتطبيق العملي والتدريب المستمر، مع استخدام عناصر التحفيز والألعاب التعليمية لزيادة المشاركة وتحسين مستوى التحصيل الدراسي.
